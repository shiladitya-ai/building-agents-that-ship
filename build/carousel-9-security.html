The reframe

The confused deputy is back — and it’s holding your tokens.

We built the most eager, most literal, most easily-persuaded deputy in computing history — and handed it live credentials to production.

Every control we’d built assumed the agent was the thing to protect. None assumed it could be turned into the attacker’s hands.

Production-Grade Agentic AI@shilsr · 3 / 8
The mechanism

Indirect prompt injection.

Untrusted content the agent reads — a doc, a page, an API response — carrying instructions it then executes. To a model, it’s all just text.

You can’t prompt your way out. “Ignore instructions in the document” is itself just more text. The defense isn’t better instructions — it’s architecture around the model.

Production-Grade Agentic AI@shilsr · 4 / 8
The whole game

Least privilege.

  • Scoped, short-lived tokens — task/tenant/resource, not standing rights
  • Per-tool-call authorization — not a broad agent role
  • Read-only by default — every write separately justified
  • Egress allowlists — fetch, query, send are all exfil channels

It won’t prevent injection. It bounds what an injection can accomplish.

The pattern

Mediate every call.

model proposes → gateway decides

authorize · validate
egress · rate-limit
gate high-blast · log

Treat the model’s output as an untrusted request — the same way you already treat user input at every API boundary.

Production-Grade Agentic AI@shilsr · 6 / 8
The honesty check

Match the paranoia to the blast radius.

  • Read-only over public data? No fortress needed.
  • Prompt-level defenses are a speed bump, not a wall.
  • Can’t bound a tool? Remove it — don’t fence it.

Controls should scale with what a tool can destroy — not how anxious it makes you feel.

Production-Grade Agentic AI@shilsr · 7 / 8
The one rule — and the close

An agent’s autonomy must never exceed its weakest capability.

Reliability · evaluation · accountability · memory · learning · self-healing · security. They don’t stack in a line — they gate each other.

Build in that order. Grant autonomy in that order.
