The trap

“It forgot → give it a bigger window.”

Wrong instinct. Two reasons it backfires:

  • Lost in the middle — models don’t read long context evenly. Bury a rule mid-prompt and you’ve hidden it, not saved it.
  • Geometric decay — long horizons rot (success ≈ r^H). Cramming the context steepens the decay.

More tokens is not more memory.

Production-Grade Agentic AI@shilsr · 3 / 8
The reframe

Memory is an architecture, not a prompt.

The context window isn’t storage. It’s working memory — scarce, volatile, expensive. Think like an OS:

Context window
= RAM
⇄
External store
= disk

The agent pages information between them — evicting what’s cold, retrieving what’s suddenly relevant.

Production-Grade Agentic AI@shilsr · 4 / 8
Name your memory tiers

Three kinds of memory.

Working

the live window — curated per step, holds only what’s needed now

Episodic

what happened — a searchable log of interactions, actions, results

Semantic

durable facts, decisions & constraints — “prod frozen until the 30th”

Production-Grade Agentic AI@shilsr · 5 / 8
The discipline

Retrieve, don’t retain.

Don’t accumulate history in the window. Keep it in a store and pull the relevant slice back each step. The hard part is what to pull — so score it:

Relevance  +  Recency  +  Importance

A hard constraint outranks small talk — and never gets evicted.

Production-Grade Agentic AI@shilsr · 6 / 8
The step teams skip

Reflect raw history into durable facts.

Week one’s hour-long conversation shouldn’t stay an hour-long transcript forever. Compress it.

“we talked for an hour”  →  “prod is frozen until the 30th”

Reflection is how episodic memory becomes semantic — how a conversation becomes a constraint you can always afford to keep.
